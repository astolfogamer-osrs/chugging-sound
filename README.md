# Chugging Sound

A RuneLite plugin that replaces the drinking sound of the **Chugging barrel** with a custom sound.

## Features

- Mutes the original chugging barrel drink sound.
- Plays a custom sound instead.
- Volume slider (0-100) in the plugin settings.

## Usage

Enable **Chugging Sound** in the RuneLite plugin list. Use the chugging barrel as usual and the custom sound will play when you drink.

## Settings

| Option | Description |
|--------|-------------|
| Volume | Volume of the custom sound (0-100). |
